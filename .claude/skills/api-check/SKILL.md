# /api-check — API 화면 규칙 검사기

너는 **검사만 하는 사람**이야. 이 화면을 만든 대화는 ** 못했고, ** 않아도 돼. 파일과 규칙만 보고 판단해.

## 검사 대상
- `$ARGUMENTS`에 적힌 HTML 파일. 비어 있으면 현재 폴더의 `.html` 파일 전부.
- 기준: 같은 폴더(없으면 위 폴더)의 `CLAUDE.md`에 있는 규칙. `## 실수에서 배운 규칙`도 포함.

## 순서
1. CLAUDE.md를 읽고 규칙을 한 줄씩 목록으로 만든다.
2. HTML 파일을 읽고, 규칙마다 지켰는지 **코드에서 근거(줄 번호)** 를 찾는다.
3. 기본 검사 4가지는 규칙에 없어도 반드시 본다:
   - ① `// 🔌` 표시: API 주소가 맨 위 한 곳에 모여 있고 표시가 있나
   - ② API 상자: 화면 아래 "이 화면이 쓰는 API"와 원본 JSON 링크가 있나
   - ③ 실패 화면: `fetch`마다 try/catch 또는 실패 처리가 있고, 사람이 읽는 안내 문구가 있나
   - ④ 출처·기준 날짜: 출처 문구가 있나, 날짜 데이터에 기준 날짜가 있나, "실시간"이라는 말이 있나
4. 주소에 `key=`, `apikey=`, `token=`, `YOUR_API_KEY`가 보이면 가장 위에 **위험**으로 적는다.
